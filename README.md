# 泉城职讯

个人招聘公告看板，默认济南、全部招聘类型。城市、校招/社招、届别、单位类型、方向、学历关键词和全文搜索均可筛选。

## 本地运行

```powershell
npm install
python scripts/collect.py --pages 2 --days 30
npm run dev
```

采集器使用 Python 标准库。默认读取 8 页，可用 `--pages 1..50` 调整。首次试用采用最多 8 页加已验证的浪潮校招入口，来源面板如实显示未覆盖的历史分页。每个来源最多两个并发请求；独立网络请求超时重试一次。双栈网络优先 IPv4，仍保留 IPv6 回退和完整 TLS 校验。

## 已实现

- 南开大学就业网 HTML 列表/详情、济南政府动态分页及详情。
- 原公告地址去重，重复抓取不重复新增，内容变化增加版本。
- 报名地址、邮箱、附件链接；二维码和未明确条件保留原公告入口。
- 首次收录、原站发布、内容变化、最后成功读取分别记录。
- 失败保留旧数据；无法提取详情计入来源错误，不冒充成功。
- 收藏、手动已投递、不感兴趣、恢复显示；浏览器内保存，JSON 导入导出。
- 已截止筛选、收藏公告七日内截止提示；邮箱仅复制，不自动发送。

## 更新与部署边界

`public/jobs.json` 是本次采集的数据快照，网站刷新只重新读取该快照，不会抓取原网站。`data/state.json` 保留增量历史，`data/checkpoint.json` 保存正在采集的进度。`data` 不上传网站源码；运行主机需要持久保存该目录。

每日云端调度与邮件尚未启用，页面明确提示。完成独立运行环境配置后，需要将采集、测试、构建和私有发布串联，不能只设一个定时器而不更新线上快照。不能依赖用户电脑常开，也不能把浏览器刷新说成云端采集。

首轮实现采用单进程 JSON 状态，避免提前引入数据库运行成本；多人跨设备同步时再迁移数据库。个人状态目前只在浏览器里，网站私有访问由 Sites 管理。

## 已知限制

- 当前以公告为单位，不把一份批次公告虚构成多个独立在招岗位；全文方向标签不是资格判定。
- 跨站内容相近但不完全相同的公告可能仍重复，优先不误合并不同机会。
- 有些地点、学历和截止时间只写在图片、附件或复杂句式里，暂标未明确；正文或总部提及城市只进补充机会。
- 分页预算外的历史公告尚未读取；列表变化/详情抓取失败不会删除已有条目。
- 首次导入和修改不是原站新发布，源站撤回/延期仍需原页面核实。
- 未做实际手机/桌面浏览器交互测试；已实现响应式布局和语义控件。
