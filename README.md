# 职讯雷达

个人招聘公告看板，默认济南、全部招聘类型。城市、校招/社招、届别、单位类型、方向、学历关键词和全文搜索均可筛选。

## 本地运行

```powershell
npm install
python scripts/collect.py --pages 100 --days 180
npm run dev
```

采集器使用 Python 标准库。默认最多 100 页、120 天，可用 `--pages 1..500 --days 1..365` 调整。来源面板区分读至末页、达到日期边界和页数预算，不能把预算内成功当作全历史覆盖。每个来源最多两个详情并发请求；独立网络请求超时重试一次。双栈网络优先 IPv4，仍保留 IPv6 回退和完整 TLS 校验。

可用 `--sources jobsdufe-positions,ujn-positions` 只刷新指定渠道，其他来源与历史记录继续保留。默认复用 24 小时内读取过的详情；`--refresh-hours 0` 强制重读。省平台列表已包含正文，不重复请求每条详情。每完成一个来源保存状态，降低中途中断的损失。

定向补漏示例：`--sources nankai --nankai-area 15` 读取南开原站山东省列表；`--sources offerjack --target-city 济南` 读取公开线索的济南列表。城市参数可替换，省份编号来自原站选项。定向采集不代表其他城市被同步完整更新。

## 已实现

- 南开大学、山东大学就业网列表/详情；济南市政府、人社局、国资委动态招聘列表。
- 山东财经大学、济南大学、山东理工大学、齐鲁工业大学：招聘公告和具体岗位分别采集，后者保留学历、要求、工作地区划代码、截止时间。
- 超级简历公开校招元数据作为补充线索，明确标注第三方、收录日期及未经企业原文复核；不读取登录后联系方式或复制编辑建议。
- Jacky学长校招公开接口提供企业、批次、毕业届别、岗位方向、城市、原公告和投递入口；只使用无需身份认证的公开数据，拒绝状态不尝试登录后替代。
- 严格按原公告发布日期倒序，日期未知置后；地点待确认逐条标注。
- 原地址增量去重；跨站标题、正文、岗位类型和工作地完全相同才折叠，并保留其他来源入口。不同地点或正文不误合并。
- 报名地址、邮箱、附件链接；二维码和未明确条件保留原公告入口。
- 首次收录、原站发布、内容变化、最后成功读取分别记录。
- 失败保留旧数据；无法提取详情计入来源错误，保留已核实列表的标题、日期、原文入口并注明详情待核对，不冒充详情解析成功。
- 收藏、手动已投递、不感兴趣、恢复显示；浏览器内保存，JSON 导入导出。
- 已截止筛选、收藏公告七日内截止提示；邮箱仅复制，不自动发送。

## 更新与部署边界

`public/jobs.json` 是本次采集的数据快照，网站刷新只重新读取该快照，不会抓取原网站。`data/state.json` 保留增量历史，`data/checkpoint.json` 保存正在采集的进度。`data` 不上传网站源码；运行主机需要持久保存该目录。

每日云端调度与邮件尚未启用，页面明确提示。完成独立运行环境配置后，需要将采集、测试、构建和发布串联，不能只设一个定时器而不更新线上快照。不能依赖用户电脑常开，也不能把浏览器刷新说成云端采集。

首轮实现采用单进程 JSON 状态，避免提前引入数据库运行成本；多人跨设备同步时再迁移数据库。个人状态只在当前浏览器里，按用户要求网站公开免登录。

## 已知限制

- 具体岗位和批次公告分别标识。总信息条数既不是招聘人数，也不是企业数量；全文方向标签不是资格判定。
- 跨站内容相近但不完全相同的公告可能仍重复，优先不误合并不同机会。
- 有些地点、学历和截止时间只写在图片、附件或复杂句式里，暂标未明确。仅总部提及城市不参与城市匹配，山东省青岛市这样的地址不会误算济南；省级范围单列待核实。
- 分页预算外的历史公告尚未读取；列表变化/详情抓取失败不会删除已有条目。
- 首次导入和修改不是原站新发布，源站撤回/延期仍需原页面核实。
- 未做实际手机/桌面浏览器交互测试；已实现响应式布局和语义控件。
