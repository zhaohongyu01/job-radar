# 精简浏览索引与按需全文（2026-10-28）

本轮在已有 Gemini、R1–R8 和日历续采改动上继续优化全量列表加载。已在本地实现并验证，尚未提交、推送、部署或触发生产采集。前一批记录见 [优先改进记录](priority-improvements-20261028.md)。

## 完成的行为

新页面优先读取可选 `browse_index.version=1` 的精简列表。完整原始列表、详情、搜索资产和来源记录继续保留；旧页面忽略新字段，仍可读取原列表。没有精简索引或版本暂不支持时，新页面继续兼容原格式。

精简列表保留标题、企业、工作地点证据、同岗位资格匹配字段、届别、性质、有效性证据、日期、岗位 ID / 合并别名及完整宣讲信息。卡片摘要只传前 120 个 Unicode 字符；完整摘要与正文可搜索，详情按原分片读取。完整公告中的薪资和招聘阶段先计算为筛选依据，不会因摘要后半段没有随列表传输而丢失。

构建端直接调用现有 TypeScript 领域函数生成薪资、选拔通知、长期招募、变更日期和来源计数，前后端不各写一套解析规则。薪资的“以上”上界以 JSON `null` 表示无穷，读取时恢复。日期范围仍在用户浏览时计算，保留截止、变更窗口及日程随时间推进的行为。

列表中的完整历史说明、分类说明、来源明细移入按需详情；列表保留筛选需要的日期、详情待核对标记与来源名称/数量。正文、完整摘要、原始渠道记录仍可还原。已有收藏、投递、已读、备注与旧 ID 深链继续使用原 ID / `duplicate_ids`。

## 数据契约与文件

| 文件 | 职责 |
| --- | --- |
| `lib/browse-index.ts` | 从完整列表生成浏览投影、验证筛选依据 |
| `lib/jobs.ts` | 复用薪资、阶段、变更、来源函数；版本化依据的读取 |
| `lib/salary-display.ts` | 卡片和构建端共享薪资显示提取；卡片组件保留原导出入口 |
| `scripts/build_browse_index.mjs` | 校验原资产、生成内容哈希浏览分片、最后更新入口与 manifest |
| `scripts/audit_browse_index.mjs` | 对同一份完整数据做字段、筛选、搜索和日程一致性及体积检查 |
| `lib/snapshot-loader.ts`、`app/page.tsx` | 选择精简分片、继续完整数量校验、按需全文及旧版回退 |
| `scripts/snapshot_assets.py` | staging 和仅发布下载包含新增浏览资产 |

`listing_facts.version=1` 是浏览契约：省略的布尔项表示 false，省略的日期/来源数组表示空，省略薪资表示未解析到；不会从缩短后的摘要重新猜测这些字段。前端只有在整份浏览索引校验完数量和唯一 ID 后才发布完整统计，失败依旧撤回临时预览或保留已有完整快照。

浏览列表先使用原去重函数完整合并，再生成投影。浏览器不对已合并的局部预览重复去重，以免短摘要参与判断改变记录身份。来源名称缺失时仍保留渠道数量。

全文搜索复用原搜索分片，仅对原搜索中未包含的完整摘要增加补充分片；补充值同时保留原正文，避免覆盖后只剩摘要。首次不搜索就不下载全文；不打开详情就不下载详情。

## 同一数据前后对比

输入为保留在本机的 10 月 26 日历史状态：32,411 条原始来源，20,823 条公开合并列表，采集时间 `2026-10-26T07:06:52+08:00`。这不是当前线上最新数量，也不是前一批 21,043 条最终快照的同一输入。

| 指标 | 完整列表 | 精简浏览列表 |
| --- | ---: | ---: |
| 列表条数 | 20,823 | 20,823 |
| 分片数 | 14 | 10 |
| 原始 JSON 字节 | 51,542,425 | 37,634,024 |
| 分片 gzip 合计字节 | 7,647,384 | 4,811,096 |
| 首片原始字节 | 261,393 | 261,352 |
| 首片 gzip 字节 | 39,615 | 31,606 |

完整列表传输估算减少约 **37.1%**，JSON 输入体积减少约 **27.0%**。gzip 为本地计算，实际 CDN 压缩与耗时受网络、缓存和设备影响。完整列表原资产继续用于兼容与还原，不能把整个发布目录大小说成也减少 37%。浏览器仍需加载约 37.6 MB 的列表 JSON，内存和 CPU 上限仍可继续优化。

生成浏览资产本机一次约 **2.027 秒**，网络请求为零；不增加源站采集、详情请求或 NAS 时间预算。两条发布流程在合并后、staging 前执行此生成步骤；只需 Node 22.13+ 原生能力，不新增 npm 依赖或要求 NAS 重建镜像。实际云端新增处理时间和 NAS 整轮时间尚未上线实测。
