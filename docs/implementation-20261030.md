本轮按[后续计划](roadmap-20261030.md)开发。基线 `af79dd4`，保留接手时已有界面、个人记录与两期企业口碑修改。**本地已实现和验证；未提交、推送、部署、触发Actions或向真实数据分支写入。**

## 已交付的操作

1. **待投递**：顶部数字和左侧入口使用同一条件（已收藏、未投递、未隐藏、未截止），并按同一截止规则排序。点击后清除发现页的限制，其他城市的收藏仍可到达；“我的收藏”继续保留历史。
2. **投递进度**：左侧新增阶段总览，可按准备投递、已投递、测评、面试、Offer等查看。在现有详情中修改阶段，列表和总览同步；继续使用原个人记录与跨标签页锁，不创建第二套数据。
3. **企业全部机会**：点击企业名称打开面板，汇集该准确企业范围的机会、历史记录和后续宣讲；可筛工作城市、展开更多记录、打开原岗位详情。集团、部门、子公司、分公司和未明确简称仍分开，活动举办城市不随岗位城市筛选改变。
4. **分享企业**：面板提供稳定企业链接，支持刷新和网址状态恢复；不包含个人评分、备注或投递状态。企业不在当前索引时保留链接并解释。预览阶段明确显示“企业机会预览”，完整索引到达后不丢已输入的个人备注。
5. **评价来源说明**：在“信息来源”和企业面板显示各平台的实际接入状态，区分读取资料、有内容、近期员工体验、评分及更新失败；不同平台的来源资料分别计数。

主要文件：`app/page.tsx`、`components/application-overview.tsx`、`components/employer-{drawer,workspace}.tsx`、`components/reputation-coverage.tsx`、`lib/{jobs,workspace,browsing,employer-catalog}.ts`。

- **脉脉**：核对[当前读取规则](https://maimai.cn/robots.txt)、官网和企业服务入口。自建采集器不属于列明的读取例外，尚未取得授权评价数据渠道；保留人工检索，未自动接入。未登录、绕过限制或伪装成获准的搜索服务。

可复核状态存入 `config/reputation-providers.json`。看准、脉脉未产生真实自动采集记录。

### 动态优先队列

独立工作流先有界读取本站公开索引，再根据在招机会数量、已核对企业名称、缓存年龄和冷却情况排序；老企业可通过等待年龄轮转。使用登记ID、明确别名与品牌，不模糊拼接子公司。失败后退回登记名单，不阻塞岗位采集。

### 版本与评分

索引升级到schema 2，同时兼容schema 1。来源ID、链接校验、详情文件校验和发布器支持不同provider；跨平台只有明确同一完整名称才提供来源切换，冲突身份不合并。

每个平台的原生分单独标明尺度、样本数和读取日期；本站文字倾向参考分单独计算，不平均不同平台、不拿面试评价当入职体验。列表参考分继续优先已建立的牛客来源，不挑最高平台分，也不把跨平台账号声称为已确认的独立员工。旧个人企业ID、v4备份和本机意向记录保持兼容。

没有降低评分门槛：每维至少10个去重账号、至少3个维度、近一年明确任职/实习自述；缺日期、求助、传闻、面经和身份未知不凑分。源站成功读取超过7天、参考分过有效期时停用。

另外按每条员工体验的成功读取时间限制评分有效期，避免“今天面经栏目读取成功”替七天前读取的员工体验续期；原帖近一年统计和读取新鲜度分别保留。对应过期、未来读取时间与不同栏目混合回归已补齐。

多来源浏览器用例是**合成验证**，不代表已经取得看准/脉脉内容或真实平台评分。

## 列表性能

- 页面只保留一个完整、经过校验的不可变索引缓存。声明的版本、数量和内容哈希路径均相同时复用原数组；未完成、重复ID、异常格式或取消的读取不进入缓存。
- 元数据刷新仍真实请求，详情/全文仍按新声明处理；新索引失败时保留完整旧结果。没有减少岗位、裁掉城市、跳过校验或用预览冒充全量。
- 企业聚合、去重、个人计数、届别与地点统计按实际依赖复用；未选工作城市时，不计算页面不展示的三套地点统计。

20,823条历史冻结样本的离线Node基准：初次读取10个分片约332.315ms；重复索引读取0.003–0.016ms，新增分片读取0，返回同一数组。这只是函数/文件基准，不是页面首屏。

另以同一完整数据运行隔离Edge，记录1440px/390px的首卡、全量就绪、暖刷新、长任务、堆占用与分片请求。`scripts/benchmark_browser_index.mjs` 可重复测量；本地模拟每分片150ms延迟，生产构建运行在本地Workers。报告不等于公网4G测试或真实手机CPU测试，堆占用没有强制GC，不能据此声称内存节省比例。
