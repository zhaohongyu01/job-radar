## 根因和修改

1. 临沂岗位在上一轮14:51已成功读最新页，但15:02只剩5.7秒还启动历史回补；回补超时覆盖了整源状态。现在保留本轮真实最新页时间/页数/解析数；失败回补仍记录错误、队列和partial状态，不导致下一轮最新页因历史回补而退避。以前轮次的head时间不能掩盖本轮失败。
2. 历史回补原来与最新页共用last_list_read_at排序。最新页每轮更新相同顺序的时钟，可能造成相同学校反复先得到预算。新增last_backfill_attempt_at，历史回补按最久未尝试排序；最新页次序、轮转休眠、冷却、岗位详情核验均保留。未启动的回补不更新时间，跨轮检查已覆盖两个学校各获一次回补且两轮最新页覆盖不变。
3. 普通30秒及以上单源预算下，最后不足10秒不启动新历史回补，保存断点下轮继续；较小显式预算按其一半设置门槛。没有增加NAS1200秒、南开90秒或源站请求并发。
4. 山东高校招聘速递旧POST接口getArticleList.jsp实际失效。官网旧栏目跳转至[新公开栏目](https://gxjy.sdei.edu.cn/JobFairs/channel?classId=96)，[官网脚本](https://gxjy.sdei.edu.cn/JobFairs/jsdw/channel.js)使用GET channel/ajaxList。已改用该接口，校验栏目96、页码、结构和总页数；8秒单次0重试。保持sdei-news:id和原HTTPS公告地址；发布日期仅来自原公告路径/正文，不使用采集日期补造。
